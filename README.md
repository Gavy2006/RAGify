# 📄 RAGify

> Chat with your PDFs using AI.

RAGify is an Android application that allows users to upload PDF documents and interact with them using Retrieval-Augmented Generation (RAG). The app is being built with a modern Android UI using Jetpack Compose and will integrate a Python backend for document processing and AI-powered question answering.

## 🚀 Current Progress

- ✅ Jetpack Compose UI
- ✅ Material 3 Design
- ✅ Top App Bar
- ✅ ChatGPT-style Input Box
- ✅ PDF Picker Integration
- ✅ Send Button UI
